## About

I’m a Computer Engineering student interested in software development, data analysis, and machine learning. During an Erasmus+ traineeship at the **University of Szeged, Hungary**, I worked on performance benchmarking for selected EUDI Wallet workflows.

## Selected work

| Project | In brief |
|:--|:--|
| [**Breast Cancer Histopathology Classification**](https://github.com/03betulpehlivan/breast-cancer-histopathology-classification) | Binary image-classification research combining ViT, Swin Transformer, and ConvNeXt features, with MLP and RBF-SVM classifiers. |
| [**EUDI Wallet Performance Benchmark**](https://github.com/03betulpehlivan/eudi-wallet-performance-benchmark) | Latency and performance analysis of selected wallet issuance and verification workflows, developed during my Erasmus+ traineeship. |
| [**Turkey Gold Price Forecast**](https://github.com/03betulpehlivan/turkey-gold-price-forecast) | Work in progress exploring Turkish physical gold prices alongside USD/TRY, ounce gold, and economic indicators. |
| [**WedSync**](https://github.com/03betulpehlivan/WedSync) | ASP.NET Core and SignalR event platform for QR-based photo and message sharing on live venue displays. |
| [**Roastify**](https://github.com/03betulpehlivan/Roastify) | Flutter app pairing image analysis with Gemini and Firebase for character-driven responses. |
